# Maintainers

Maintainers hold commit rights to this repository. This repository is the public record of how OpenDCKit is governed: the TSC roster, the charter, TSC policies and election results.

This list governs commit access to this repository only. It is not the Technical Steering Committee roster, which is in TSC.md in this repository.

## How changes are made here

Every change to this repository goes through a pull request and needs an approving review from someone other than the author. Neither account merges its own pull request. This is enforced by branch protection on main.

Adding or removing a maintainer is done by pull request against this file. See CONTRIBUTING in the opendckit/.github repository for the full process.
