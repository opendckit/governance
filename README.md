# OpenDCKit Governance

This repository is the public record of how the OpenDCKit project is governed. It holds the
Technical Charter, the Technical Steering Committee (TSC) roster, the policies the TSC
adopts, and the results of TSC elections.

OpenDCKit is a project of LF Networking, a directed fund of The Linux Foundation, and is
organized as OpenDCKit a Series of LF Projects, LLC.

## What is here

| Path | Contents |
| ---- | -------- |
| [`TSC.md`](TSC.md) | TSC voting members, chair, and term dates. This is the authoritative roster. |
| [`charter/`](charter/) | The adopted Technical Charter. |
| [`policies/`](policies/) | TSC operating policies, as the TSC adopts them. |
| [`elections/`](elections/) | Nominations and results for each TSC election. |

How to contribute, the roles in the project, how Maintainers are added, and how TSC voting
membership is determined are set out in the organization's
[CONTRIBUTING.md](https://github.com/opendckit/.github/blob/main/CONTRIBUTING.md), as the
charter requires. Each code repository lists its own Maintainers in its `MAINTAINERS.md`.

## Other copies of this information

The [OpenDCKit wiki](https://lf-networking.atlassian.net/wiki/spaces/OpenDCKit/overview)
and the TSC committee in LFX mirror the roster for convenience and for meeting invitations.
If they ever disagree with this repository, this repository is correct.

## Changing this repository

Every change is made by pull request. Changes to the roster, policies, or election records
reflect a decision the TSC or an election has already made, and the pull request links to
the minutes or election result that records it. Pull requests are merged by Linux Foundation
staff or the TSC chair.

Formation progress and the list of policies the TSC still needs to define are tracked on the
[Formation Status](https://lf-networking.atlassian.net/wiki/spaces/OpenDCKit/pages/1534132241)
wiki page.
